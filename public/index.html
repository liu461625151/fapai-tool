数据说明：本工具数据实时来自阿里拍卖（sf.taobao.com）司法拍卖频道，每次查询都会从阿里服务器获取最新数据。 由于阿里API每页返回10条数据，可点击"加载更多"获取后续页面。时间范围、关键词、价格和面积筛选在本地对已加载数据进行过滤。 点击"查看详情"可查看完整标的信息，点击"去竞拍"可跳转到阿里拍卖原始页面参与竞拍。导出功能可将当前筛选结果保存为CSV文件。

淘宝登录Cookie设置

使用说明：
1. 在浏览器中登录 淘宝 或 阿里拍卖
2. 按 F12 打开开发者工具 → 切换到 Network（网络）标签
3. 刷新页面，点击任意请求，在 Request Headers 中找到 Cookie，复制完整内容
4. 粘贴到下方输入框，点击保存
⚠️ Cookie包含你的登录信息，请勿分享给他人。Cookie过期后需要重新获取。
